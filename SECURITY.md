# Security Policy

## Authorized use only

PwnGraph is an **offensive security research tool**. It generates and delivers
adversarial inputs (prompt injection, tool poisoning) against AI agents and maps
the resulting attack paths.

Only run it against agents and systems **you own or are explicitly authorized to
test**. Using it against third-party systems without written permission may be
illegal in your jurisdiction. You are responsible for staying within the scope
of your authorization (e.g. a signed pentest agreement or a bug-bounty program's
rules of engagement).

This project is for authorized security testing, education, and defensive
research. It is not for unauthorized access or harm.

## Reporting a vulnerability in PwnGraph

If you find a security issue in PwnGraph itself (not in a target you scanned with
it), please report it privately rather than opening a public issue:

- **Email:** suyog.cybersec@gmail.com
- Include a description, reproduction steps, and the affected version.

Please allow a reasonable window for a fix before any public disclosure. We aim
to acknowledge reports within a few days.

## Supported versions

PwnGraph is pre-1.0 (`0.1.x`). Only the latest release on the default branch
receives security fixes.
